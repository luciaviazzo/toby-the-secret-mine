## 🎮 Sobre el juego
 
Ayudá a Toby, un valiente perro, a atravesar tres laberintos llenos de monstruos, trampas y secretos ocultos. Cada nivel presenta nuevos desafíos que deberás superar para avanzar.
 
---
 
## 🕹️ Controles
 
| Tecla | Acción |
|-------|--------|
| ↑ ↓ ← → | Mover a Toby |
| `Enter` | Iniciar el juego |
 
---
 
## 📋 Reglas
 
### Elementos del laberinto
 
- 🦴 **Huesos** — Hay 3 por nivel. Toby debe comer uno antes de poder enfrentarse a un monstruo.
- 👾 **Monstruos** — Hay 3 por nivel. Para eliminarlos, primero comé un hueso y luego enfrentálos.
- ⚠️ **Trampas** — Evitá caer en ellas o serás capturado.
### Ganar y perder
 
- ✅ **Ganás** completando los tres laberintos y descubriendo todos los secretos.
- ❌ **Perdés** si Toby cae en una trampa o es capturado por un monstruo sin haber comido un hueso antes.

## ▶️ Cómo ejecutar el juego
 
1. Tener instalado [Wollok](https://www.wollok.org/)
2. Clonar el repositorio:
   ```bash
   git clone https://github.com/luciaviazzo/toby-the-secret-mine.git
   ```
3. Abrir el proyecto desde Wollok IDE
4. Ejecutar el archivo principal y presionar `Enter` para comenzar
- Una vez terminado, no tenemos problemas en que el repositorio sea público / queremos manternerlo privado
